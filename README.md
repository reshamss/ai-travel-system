# 🌍 AI Travel Suggester System ✈️🧳

An intelligent and interactive travel recommendation web app that helps users find the perfect travel destination based on their preferences for climate, budget, and distance. Built using Django and Python, this system offers a seamless user experience with AI-driven suggestions.

---

## 📌 What It Does

The AI Travel System suggests travel locations based on:

- 🌤️ **Preferred Climate**
- 💸 **Budget Range**
- 📍 **Distance/Location**
- 🧠 **AI-based Decision Logic**

---

## 🖥️ Key Features

- 🧭 Smart destination recommendations
- 🎯 Personalized travel results based on user input
- 📬 Contact form for inquiries or suggestions
- 📱 Responsive UI with clean design
- 🌐 Ready for deployment on platforms like Render

---

## 🛠 Tools & Technologies Used

- 💻 **Frontend**: HTML, CSS, Bootstrap  
- 🧠 **Backend**: Django (Python)  
- 🗃️ **Database**: SQLite  
- 📊 **Recommendation Logic**: Rule-based AI using condition matching  
- 📨 **Contact Form**: Email backend in Django
